# WhatsApp Mon

Copyright (C) 2026 WhatsApp Mon contributors

Visualizador local e somente leitura para backups Android descriptografados do WhatsApp.

O aplicativo principal está em [`web-apps/whatsapp-viewer`](web-apps/whatsapp-viewer). Ele oferece conversas paginadas, pesquisa FTS5, mídias locais, contatos, grupos, chamadas, importação/exportação de contatos e acesso HTTPS protegido por senha.

## Privacidade

Este repositório não contém bancos, mídias, contatos, certificados, senhas ou chaves de backup. Esses itens permanecem apenas no computador do proprietário e são ignorados pelo Git.
